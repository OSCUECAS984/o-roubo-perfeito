# Versões do jogo

Cada pasta guarda o jogo exatamente como saiu naquela versão (`index.html`, `css/` e `js/`). O vídeo, os sons e o desenho do museu são os mesmos em todas as versões e ficam na pasta [`assets/`](../assets/) da raiz. Para jogar uma delas, abra o `index.html` da pasta no navegador.

A **v2.0.1 é a versão final de lançamento**. Ela é idêntica ao jogo da raiz do repositório.
